## 🚀 Как запустить у себя?

## 📦 Окружение

- Node.js v22.13.1
- npm v10.9.2

- [Node.js](https://nodejs.org/) — установка Node.js
- [NPM](https://www.npmjs.com/) — менеджер пакетов npm

1. Клонируйте репозиторий:

```bash
git clone ...
```

2. Перейдите в папку проекта:
3. Установите зависимости:

```bash
npm install
```

4. Запустите проект:

```bash
npm run davS
```
